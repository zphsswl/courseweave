## 1. 通用说明

## 6. RAG 问答

RAG 问答基于 DeepSeek v4-pro 引擎，通过向量检索 + LLM 生成的方式提供精准医学问答服务。

### 6.1 提问

```
POST /api/rag/query
```

**请求体**：

```json
{
    "question": "请解释肝硬化的门脉高压形成机制"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| question | string | 是 | 用户问题，最少 2 字符 |

**成功响应 200**：

```json
{
    "answer": "根据教材内容：肝硬化时，肝星状细胞激活转化为肌成纤维细胞...\n[病理学, 第十二章 肝硬化, 第332页]",
    "citations": [
        {
            "textbook": "病理学",
            "chapter": "第十二章 肝硬化",
            "page": 332,
            "relevance_score": 0.95
        },
        {
            "textbook": "病理生理学",
            "chapter": "第五章 肝性脑病",
            "page": 183,
            "relevance_score": 0.91
        }
    ],
    "source_chunks": [
        "原文片段1...",
        "原文片段2..."
    ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| answer | string | 生成的回答（含引用标记） |
| citations | array | 引用列表（教材/章节/页码/相关性评分） |
| source_chunks | array | 原始检索片段（前 500 字符） |

**说明**：
- 使用 DeepSeek v4-pro 生成回答，温度参数 0.3
- 仅依据教材原文片段回答问题，超出范围时回答"当前知识库中未找到相关信息"
- 引用格式为 `[教材名称, 章节名称, 第X页]`

### 6.2 建立 RAG 索引

```
POST /api/rag/index
```

将数据库中的 Chunk 数据编码为向量并存入 ChromaDB。

**成功响应 200**：

```json
{
    "indexed": 8440
}
```

### 6.3 索引状态检查

```
GET /api/rag/status
```

**成功响应 200**：

```json
{
    "indexed": true,
    "chunk_count": 8440,
    "chroma_count": 8440,
    "in_sync": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| indexed | bool | 索引是否构建完成 |
| chunk_count | int | 数据库中的 Chunk 数量 |
| chroma_count | int | ChromaDB 中的向量数量 |
| in_sync | bool | 两者是否一致（允许 ±10% 误差） |

## 7. 教师对话与决策管理

教师可通过自然语言对话与知识图谱决策系统交互，支持查看、修改和解释整合决策。

### 7.1 教师对话

```
POST /api/chat
```

**请求体**：

```json
{
    "message": "请把抗原和免疫原分开，它们不是同一个概念"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| message | string | 是 | 教师消息（自然语言） |

**成功响应 200**：

```json
{
    "response": "已将决策 dec_xxx（抗原/免疫原）改为拆分。知识点将保持独立。",
    "operation": "split",
    "parsed": {
        "operation": "split",
        "decision_id": "dec_xxx",
        "target_nodes": ["抗原", "免疫原"],
        "reason": "教师认为概念不同需要拆分"
    }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| response | string | 系统回复 |
| operation | string | 识别到的操作类型（keep/merge/split/remove/explain） |
| parsed | object | 解析结果详情 |

### 7.2 获取决策列表

```
GET /api/decisions
```

**查询参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| skip | integer | 否 | 0 | 跳过条数 |
| limit | integer | 否 | 50 | 返回条数 |

**成功响应 200**：

```json
[
    {
        "id": "dec_abc123",
        "action": "merge",
        "affected_nodes": ["node_001", "node_002"],
        "result_node": "merged_abc123",
        "result_name": "肝硬化",
        "reason": "高相似度自动合并 (sim=0.923)",
        "confidence": 0.923,
        "teacher_override": false,
        "teacher_feedback": "",
        "created_at": "2026-05-10T14:30:00Z"
    }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| action | string | 决策动作（merge/keep/remove/split） |
| affected_nodes | array | 受影响节点 ID 列表 |
| result_name | string | 合并后的结果名称 |
| reason | string | 决策理由 |
| confidence | float | 置信度 |
| teacher_override | bool | 是否被教师覆盖 |
| teacher_feedback | string | 教师反馈内容 |

### 7.3 修改决策

```
PATCH /api/decisions/{decision_id}
```

**请求体**：

```json
{
    "action": "split",
    "reason": "教师要求将概念分开",
    "feedback": "请分开这两个概念"
}
```

**成功响应 200**：

```json
{
    "status": "updated",
    "id": "dec_abc123"
}
```

### 7.4 获取对话历史

```
GET /api/chat/history
```

**查询参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |

| skip | integer | 否 | 0 | 跳过条数 |
| limit | integer | 否 | 50 | 返回条数 |

**成功响应 200**：

```json

    {
        "id": "chat_abc123",
```

## 10. 异步任务

系统通过 Job 机制支持异步后台任务，涵盖解析、图谱提取、整合压缩和 RAG 索引等。

### 10.1 启动解析任务

```
POST /api/jobs/parse
```

**请求体**：

```json
{
    "textbook_id": "book_abc123"
}
```

**成功响应 200**：

```json
{
    "id": "job_abc123",
    "type": "parse",
    "status": "pending",
    "progress": 0,
    "total": 0,
    "message": "",
    "result": {},
    "error": "",
    "created_at": "2026-05-10T14:30:00Z"
}
```

### 10.2 启动图谱提取任务

```
POST /api/jobs/extract-graph
```

**请求体**：

```json
{
    "textbook_id": "book_abc123"
}
```

**成功响应 200**：返回任务对象（格式同 10.1）。

### 10.3 启动整合压缩任务

```
POST /api/jobs/integrate
```

启动跨教材对齐 + 知识压缩（目标 30%）流水线。**请求体**：空。

**成功响应 200**：返回任务对象。

### 10.4 启动 RAG 索引任务

```
POST /api/jobs/rag-index
```

将 Chunk 向量化并写入 ChromaDB。**请求体**：空。

**成功响应 200**：返回任务对象。

### 10.5 获取任务状态

```
GET /api/jobs/{job_id}
```

**路径参数**：
