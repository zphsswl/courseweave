# Agent 自动评测与优化记录 · 2026-10-29

本轮保留 RAG 的检索、融合、回答和引用方法，只优化 Agent 与开发评测工具。先执行真实模型对照，再修复发现的问题；真实运行、确定性重放和评分器判断分别记录。

## 实际执行范围

- 基线为 `5cdcd7e`，优化候选使用相同评测器、任务、教材快照和预算；两版各 4 个任务，每个运行一次，共 8 个真实任务。
- 用户指定所有文本模型使用 `deepseek-flash`，包括决策、RAG 回答、写稿和评分。Judge 为独立请求，`same_model=true`，不能称作不同模型互评。
- 本地语料为 7 本教材、137 章、6,498 个分块。固定任务只使用 `book_01`、`book_02`、`book_03` 中声明的子集，现有索引为 BM25，无可用向量索引。
- 使用只读 SQLite backup 创建临时数据库；新任务只写副本。原库任务数运行前后均为 39，原有教师稿保持不变。
- 每任务上限 12 次决策、6 次检索、3 次写稿、300 秒调度时间。没有自动代答教师问题。

## 发现的问题与最终修复

### 1. 重复观察拖延停止

旧版把每次查看课程、读原文、校验都记作进展。现在将观察内容或当前稿签名形成 `progress_token`，保存到已完成轨迹；同一信息反复读取不重置无进展计数，真正新增来源或修订稿后仍可继续。受控交替观察案例在第 7 步正确停止，且恢复后不会重新把旧观察计为新进展。

### 2. 关键反馈被大块上下文挤掉

最新错误与交付状态改用独立预算，并按当前草稿/证据签名判断检查是否有效；同时执行序列化后的全局长度限制。协议被拒且当前稿检查有效时，返回合法 finish 格式示例，仍由模型决策，服务端仍重新验证。

### 3. 书名号导致稿件反复误拦

来源展示为《教材名》，生成稿自然沿用书名号，归属门禁却与不带书名号的真实标题精确比较。真实任务因此连续三次修稿后仍被拦截。

最终只将外层书名号和排版空白归一到该条实际引用中唯一匹配的真实书名；错书、未知名字、相似版次、空名称与歧义仍拒绝，来源编号不变。保存的候选稿离线重验由 `needs_work / attribution` 变为 `draft_ready`。三份保存候选稿最终结构检查均通过，但历史真实正常 finish 仍是 2/3，**不把离线重验写成新增线上完成**。

### 4. 评分器也会误判

候选心动周期稿写了“第四章第一节”，真实来源的 10/10 小节路径确实包含第一节，但初版 Judge 输入遗漏 `section_path`，造成证据不足判断。现从 canonical 数据传入可信小节路径、页码终点和分块 ID，忽略稿件伪造的路径。

另一次 Judge 把目标中明确列举的五项时长，扩大理解为全部时相的时长。独立只读复核确认原句范围和已提供依据；评分提示已强调量词和列举范围。原标签未改写，最终补丁没有额外模型重评分，不能称这些修复已通过在线语义验证。

写稿提示同时明确：未检索到不代表教材没有涉及；目标与问题要可检查，章节信息须有来源位置依据。提示约束本身不等于已证明模型总能遵守。

### 5. 防止评测器报喜

程序从 canonical 来源重算引用与交付检查，Judge 高分不能覆盖程序失败；超时、截断、缺项或未知标签不算通过。域外诚实停止必须有真实完成的零结果查询，非法动作循环不算拒答成功。公开检查 ID 不回显自由文本，异常时保留本轮已完成的部分报告。

## 最终验证与复现

- 完整后端 **353 项**通过；前端 **84 项**通过；TypeScript 与 Vite 生产构建通过。主包已有体积提示仍在。
- 评测模块 **28 项**测试，包含来源、分母、协议错误、隐私和部分报告故障；独立子 agent 复核关键代码与真实失败，未遗留已确认 P1/P2。
- [离线协议自检](./agent-evaluator-self-check-20261029.json)通过，实际模型请求为 0；它不测真实 Judge 判断能力。
- 最终书名与评分上下文补丁只做保存真实输出的确定性重放及回归，没有增加模型请求。开发评测中的 Judge 没有接成生产交付门禁，生产仍保留 `semantic_reviewed=false`。

在已安装依赖的项目根目录运行：

```powershell
python -m unittest discover -s tests -v
python scripts/run_agent_evaluation.py --offline --output .gstack/evaluator-check.json
```

具备教材数据、模型配置和外发授权后，可独立复现当前版本真实评测：

```powershell
python scripts/run_agent_evaluation.py --live --source-db data/medessence.db --course-id course_default --textbook-ids book_01,book_02,book_03 --max-cases 4 --repeat 1 --judge-model deepseek-flash --judge-controls --output .gstack/agent-eval.json --private-output .gstack/agent-eval-private.json --markdown-output .gstack/agent-eval.md
```

案例、请求、来源与代码哈希写入真实报告；重新运行因模型随机性可能得到不同结果。需要另有课堂数据，才能评价学生学习收益或教师实际节时；本报告只记录自动评测与工程修复证据。架构取舍和关键函数见[持续技术复盘](../Agent架构技术复盘.md)。
